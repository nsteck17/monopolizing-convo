# CSCI 8920 Research Paper - "Monopolizing Conversations: Examining Developer Conversation Participation in Chat Applications"
## monopolizing-convo Tool:
1. Asked chatgpt to generate an XSD based on example dataset
2. Generated bindings from XSD (schema) to map XML to Java Objects
3. Wrote code to import XML data file 
4. Translated XML data file to Java Object(s)
5. Transformed Imported Java Object to "standardized" processing message type
6. Wrote calculator to figure out monopolization convo objects 
7. Added details used for later analysis to monopolization convo calculator
8. Wrote AnalysisProcessor to total SAME vs NEW maps to output
9. Output the results into Excel and summary output and logs
10. Combined all datasets of Discord channel into 1 processing, add select of data set
